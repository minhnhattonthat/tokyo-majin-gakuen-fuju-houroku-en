# Style reference

From the pilot (B00, the opening; in-game shot `work/qa/pilot_zoom.png`). Add a row per character as chapters land (main cast rows added 2026-11-22 from the glossary decisions and the script).

## Voices
| Speaker | JP markers | English devices |
|---|---|---|
| Woman's Voice (B00, guide in the dark) | わ/のよ/かしら, ふふ, 詩 quotes | calm, slightly teasing, complete sentences; "Heh.", "I wonder?", "Don't blame me if..." |
| Evil Spirits | ェェッ, ォ, 我ら/ヌシ, おのれ | drawn-out letters ("Waaait!!", "Womaaan--"), archaic threats ("Curse you!!") |
| Hospital staff (voices) | ッ, terse reports | clipped medical English ("Heart rate still falling!!", "we begin CPR!") |
| Yamura (Shun Yamura) | 俺, だな/のか, 馬鹿なッ, {name1}様 / {name1}殿 | earnest, stiff young summoner: "That's absurd!!", "It seems that wasn't a lie."; {name1}-sama, from B04 {name1}-dono, plain {name1} in casual talk; Enra-sama |
| Isuzu (Isuzu Mizukane) | 私, ～て/ね, ―――, {name1}くん, 俊 | warm, plain modern teen girl: "Leave this to us.", "Thank you, {name1}-kun."; calls Yamura "Shun"; Enra-sama |
| Enra | 儂, おぬし, ～だ/のだ, ―――。 | old deity, grave and kindly: "I've put you through a great deal."; never slang; trailing "--" for his pauses |
| Takamaru | 己 (おれ), お前, ～だ | plain "I/me", blunt and heavy: "My Power was born of the Shade."; cries stretch the vowel ("Toshimuuune!!") |
| Kumaso | おれ, ～だと！？, ッ！！ | mocking, sadistic: "Stop, you say!?", "Take that soul!!" |
| Uhatsura | 人間, ～ねばならない, ひゅうう | cold and formal: "Very well", "fear not", "I must part you from the Great Sin forever..." |
| Amanosagume | ～ですね (mask), あんた/～だろうさ (true voice), 若日子様 | two registers: polite ("It seems the time has come.", "Wakahiko-sama--"), then coarse ("Sure, you're not Toshimune.") |
| Water Retainer | わらわ, そなた, ～かえ | archaic thou/thee |
| Shimei / Shiroku | 貴様ら, ～のだ, incantations | formal judges' speech: "Then what about you, who've been gathering the Great Sins?" |

## Paired examples
- いつからそこに？ -> How long have you been there?
- 私に気を使う事はないわ。 -> You needn't spare my feelings.
- 待てェェッ！！ -> Waaait!!
- 生きている―――女の魂ッ。 -> A living--woman's soul!
