# Skill gotchas

- references/graphics.md §Survey: a sprite's true size is the BIOS copy length at load time (exec hook on SWI 0x08, r0 in the asset range, r2 = units), not the sweep's block guess: a redraw sized from the sweep (0x800 instead of 0x600) overwrote the next sprite set; `tools/debug/srclog.lua` logs these copies.
- SKILL.md Step 0: the plugin's own guard hook did not block the canary in an Orca worker session; adding the `hooks` block (stable marketplace path) to `.claude/settings.json` took effect a few calls later in the same session without a reload.
- references/graphics.md §Survey: GBA card games store 8bpp art (all bytes < 0x80) beside 4bpp UI; a 4bpp-only vramfind misses it ("background codec" here was just 8bpp). Split assets at 4-aligned pointer targets; odd targets are struct fields.
- references/graphics.md §Survey: 8bpp tiles can also use only palette indices >= 0x80 (here 0x81-0x9F, card frames with a 0x140-byte palette); an "all bytes < 0x80" 8bpp test skips them as "records". Follow the pointer table to (tiles, palette, map) triples instead.
- references/pipeline.md §Extract: a "the byte before a pointer target is 00" rule (to drop graphics noise) also drops real text embedded in structs after header bytes (12 strings here) and a string that starts just before the assumed range start. Keep the rule only for pointer sites in graphics; trust sites in code, text tables and the text ranges. A ROM-wide scan for kana-heavy runs (>= half kana) outside extracted units found them; a kanji-or-fullwidth test is swamped by graphics noise.
- references/pipeline.md §Marker: story text here is drawn whole, then revealed left to right; a shot taken in the first ~40 frames of a box shows a cut-off line that looks like missing glyphs. Shoot every 20 frames and use the last shot of each box before judging.
- references/emulator-qa.md §Debug tool: a mash route picks every choice menu within ~10 frames, so a tour never shows the menu. Save a state a few lines before it and replay with scripted presses that stop before the menu opens (`tools/debug/choicetest.ps1`).
- references/pipeline.md §Marker (engine spike): when every printer calls one per-cell glyph routine and moves one cell per u16 unit, a VWF needs no printer changes: hook the routine, make English units MTE codes (1-4 chars) in unused lead bytes, keep a pixel cursor across consecutive cells, and have the encoder keep each strip's ink <= 16 px x units handed out (`tools/vwf.py`). keystone ARM mode handles labels and `.word` literals; `str.format` on asm text breaks on `{r4-r7}` register lists.
- references/pipeline.md §Extract: the context-mode plugin returns a stub for a whole-file Read of a ~5 KB `.py` and for Bash output above a few KB, even with `cat`; read source with offset/limit.
- references/pipeline.md §Marker (engine spike): "every printer calls one glyph routine" was wrong here: a second printer (yes/no prompts, sprites) decodes Shift-JIS itself, so the VWF hook and the glyph probe missed it and its marker drew blank. Find such paths by looking for blank boxes in the marker tour and watching ROM reads of that string (`lua/probes/watch.lua` with WATCH_MODE read); give the probe every glyph entry point.
- references/emulator-qa.md: GBA sprite/BG text often comes in by DMA3 (vramsrc-style write hooks see pc after the DMA, no source register); vramfind.py on the PPU dump finds raw sources faster.
- references/emulator-qa.md: a GBA routine's caller hidden behind a BIOS copy (pc < 0x4000) is found by an exec hook on the SWI vector 0x00000008 in Mesen: cpu.r14 there is the return address in the SWI wrapper; then hook the wrapper (here 0x080635DC CpuFastSet) for its lr.
- references/emulator-qa.md: `L.dump_ppu(prefix)` (mesen_lib.lua) resolves the prefix against the run's `--out` dir, so a prefix that already contains the out dir writes to `<out>/<out>/...` and fails ("No such file").
- references/graphics.md §Parallel redraws: widening a sprite label can collide with OBJ VRAM that other code writes at fixed tile numbers (here a popup at tile 640 inside a bump-allocated region); grep the code for 0x0601xxxx literals in the screen's code range and test every transient (popups, sort, scroll) after relocating tiles.
