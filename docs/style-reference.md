# Style reference

From the pilot (B00, the opening; in-game shot `work/qa/pilot_zoom.png`). Add a row per character as chapters land.

## Voices
| Speaker | JP markers | English devices |
|---|---|---|
| Woman's Voice (B00, guide in the dark) | わ/のよ/かしら, ふふ, 詩 quotes | calm, slightly teasing, complete sentences; "Heh.", "I wonder?", "Don't blame me if..." |
| Evil Spirits | ェェッ, ォ, 我ら/ヌシ, おのれ | drawn-out letters ("Waaait!!", "Womaaan--"), archaic threats ("Curse you!!") |
| Hospital staff (voices) | ッ, terse reports | clipped medical English ("Heart rate still falling!!", "we begin CPR!") |

## Paired examples
- いつからそこに？ -> How long have you been there?
- 私に気を使う事はないわ。 -> You needn't spare my feelings.
- 待てェェッ！！ -> Waaait!!
- 生きている―――女の魂ッ。 -> A living--woman's soul!
