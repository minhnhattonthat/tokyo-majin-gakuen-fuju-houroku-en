# Each glyph: a line "= C" (C = the character, or "= U+XXXX"), then 11 rows: rows 0-8 cap height (baseline after
# row 8), x-height starts at row 3, rows 9-10 descenders. '#' = ink (colour F), '.' = empty. The renderer adds the
# game's shadow (colour D) right, below and diagonally of every ink pixel, as the Japanese glyphs have it, and
# places row 0 at cell row 4. Advance = glyph width + 2 (shadow column + one gap), space = 4.
